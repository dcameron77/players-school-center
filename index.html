Import format: one row per assignment with columns name, position, year, course, assignment, due, status. Status can be submitted, missed, or upcoming. Imports merge into the board — a player's first full report adds them, and daily change files only update their assignments. A ready-made example is in sample-data.csv. Each player's Muse sends the first full report and daily updates to the coach by email with this CSV format included.

How this works with your players' Muse accounts

  1. Each player pastes the shared Muse prompt into their own Muse account.
  2. Their Muse checks Canvas daily at 5:00 PM and emails you when work is missed or turned in.
  3. You paste or import those updates here — or type them in — and this page turns the team green, yellow, or red.
  4. Red first. Yellow next. Green needs no meeting.
